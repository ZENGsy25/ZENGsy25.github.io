# 列表自定义添加命令可重写的方法W

  • 列表可重写的方法：
  • canExecute:function(entity){} 是否可以执行操作的方法，用于控制命令是否可操作，（置灰禁用|高亮可用），返回值为true时可用，返回值为false时禁用，默认为true;该方法列表每个单元格数据的变更都会执行进来，所以不建议在该方法中去处理后端数据库的逻辑。
  • execute:function(view,source){} 添加命令执行的入口，即点击添加按钮要实现的逻辑处理，添加命令执行的入口继承的添加命令。
  • getEditEntity:function(){} 获取当前行操作的实体数据，返回当前行操作的实体数据，该方法基本使用框架默认的逻辑就能满足业务需求，不建议重写该方法。
  • createNewItem:function(){} 创建新的一行，该方法基本使用框架默认的逻辑就能满足业务需求，不建议重写该方法。
  • onItemCreated:function(entity){} 实体创建后的方法，该方法可以进行默认值的设置和属性变更时间的注册

/**
 * 自定义添加命令 - 以弹框（Dialog）方式添加读者信息
 * 继承自 SIE.cmd.Add，实现添加功能的弹框展示
 * 所属模块：SIE.Web.LibMan.ReaderMans（读者管理模块）
 */
SIE.defineCommand('SIE.Web.LibMan.ReaderMans.Commands.AddReaderManCommand', {
    // 继承自添加命令基类
    extend: 'SIE.cmd.Add',
    
    /**
     * 元数据配置
     * text: 按钮显示文本
     * group: 按钮分组，edit表示编辑组（新增、修改、删除属于编辑组）
     * iconCls: 按钮图标样式
     */
    meta: { 
        text: "添加",                    // 按钮显示文字
        group: "edit",                  // 属于编辑组
        iconCls: "icon-AddEntity icon-green"  // 图标样式（绿色添加图标）
    },
    
    /**
     * 显示视图 - 重写父类方法，以弹框方式展示添加表单
     * @param {Object} editEntity - 要编辑的实体对象（新创建的实体）
     */
    showView: function (editEntity) {
        var me = this;  // 保存当前命令实例的引用，用于回调中访问
        
        /**
         * 步骤1：获取视图元数据
         * 如果视图元数据尚未加载，则异步获取
         */
        if(!this.view.getParent()){//不存在父实体，就走Dialog弹框，存在父实体，就走Tab页签
          if (!this.viewMeta) {
              SIE.AutoUI.getMeta({
                  async: false,                    // 同步加载，确保元数据获取完成后再继续执行
                  isDetail: true,                  // 指定为详情视图（表单视图）
                  ignoreQuery: true,               // 忽略查询条件，不加载查询面板
                  model: this.view.model,          // 实体模型类型
                  viewGroup: "AddViewGroup",       // 视图组名称，指定使用哪个视图配置
                  callback: function (meta) {      // 元数据加载完成后的回调函数
                      meta.token = me.view.token;  // 将当前视图的token传递给元数据
                      me.viewMeta = meta;          // 将元数据保存到命令实例中，供后续使用
                  }
              });
          }
          
          /**
           * 步骤2：构建 Dialog（弹框）配置对象
           * 包含关联命令、视图元数据、实体、编辑模式等信息
           */
          var cfg = {
              associateCmd: me,                    // 关联当前命令实例
              viewMeta: me.viewMeta,               // 视图元数据
              entity: editEntity,                  // 要编辑的实体对象
              editMode: this.view.editMode,        // 编辑模式（新增/修改）
              title: this.getEditViewTitle(editEntity),  // 弹框标题
              /**
               * 弹框确认按钮回调函数
               * 当用户点击确定/保存时触发
               * @param {boolean} isNoSave - 是否不保存（取消保存）
               */
              confirm: function (isNoSave) {
                  // 判断是否为即时保存模式
                  var isImmediate = me.view.isImmediate();
                  // 执行编辑完成后的处理逻辑（如刷新列表）
                  me.view.afterEdit(editEntity, isImmediate, me.isCopy);
                  // 执行命令的确认逻辑
                  me.confirm(editEntity, isImmediate, me.isCopy);
              }
          };
          
          /**
           * 步骤3：设置 Dialog（弹框）属性
           * 配置弹框的尺寸、样式、行为等
           */
          // 调用 setDialogAttribute 方法设置弹框属性（注意：此处缺少括号调用，实际应写作 me.setDialogAttribute(dialogcfg)）
          me.setDialogAttribute
          // 创建弹框配置对象
          var dialogcfg = {};
          // 调用 setDialogAttribute 方法获取配置后的弹框属性
          dialogcfg = me.setDialogAttribute(dialogcfg);
          // 将弹框配置添加到主配置中
          cfg.dialogcfg = dialogcfg;
          
          /**
           * 步骤4：⭐ 核心步骤 - 显示 Dialog 弹框
           * 使用 SIE.App.showDialog() 方法打开对话框
           * 这是整个命令体现使用弹框的关键
           */
          me._editingView = SIE.App.showDialog(cfg);
      },
    }else{
      //...
    },
    
    /**
     * 实体创建完成时的回调函数
     * 在实体被创建后、弹框显示前触发
     * 用于设置实体的默认值
     * @param {Object} entity - 新创建的实体对象
     */
    onItemCreated: function (entity) {
        var me = this;  // 保存当前命令实例的引用
        // entity.get属性名();//获取属性的值
        entity.set属性名(1);//设置属性的默认值为1
        /**
         * 执行视图操作
         * 调用 execute 方法获取生成的编码（如读者编号）
         */
        me.view.execute({
            data: entity.data,          // 传递实体数据
            /**
             * 执行成功回调
             * @param {Object} res - 返回结果对象
             */
            success: function (res) {
                // 从返回结果中获取生成的读者编号
                var readerNo = res.Result;
                // 设置实体的读者编号
                entity.setReaderNo(readerNo);
            }
        }, me.view);
    }
});

  • AssociateChildrenProperty：场景理解：支持跨应用，实体横向扩展，使用.RegisterExtension方法注册到A对象上的，常用来对现有对象的扩展,支持1对N关系，根据返回类型

  • AttachChildrenProperty，主表和附加的子表单为同一个实体，或者附加的字表单只是查看数据。

# 配置项

  • 配置项的定义：配置项是指可被修改的设置或参数，用于配置系统的行为和特性。允许用户根据其特定的需求进行定制，以便系统能够适应不用的环境和使用情况。
  • SMOM：的配置项是在据图的功能菜单中，开发一个配置项按钮，配置项按钮的界面是框架实现的，界面数据配置部分需要开发实现。
  • 平台的配置项包含普通属性的配置项和引用属性的配置项，普通属性的配置是在界面中配置固定值，引用属性是根据编码规则配置的规则来生成（用于单号的生成等）。

# 配置项的实现

  • 在服务端定义一个配置项实体类，命名一ConfigValue结尾，继承自ConfigValue，标记特性[RootEntity,Serializable]，使用代码段添加普通属性，重写Display方法，将值显示出来。
  • 在客户端工程添加配置界面类:实体类名+ViewConfig，继承自WebViewConfig<实体类名>，重写配置明细试图方法Config DetailsView，配置视图属性。
  • 在服务端工程定义一个规则说明类，命名取配置实体类Value之前的部分，继承自ModuleConfig<配置实体类名>，重写获取默认属性值DefaultValue，标记特性显示名称[]和描述[]。
  • 在实体中标记特性[EntityWithConfig(typeof(规则生成说明类名))]。
  • 运行项目后，可以在具体的功能中看到一个配置项按钮，点击按钮，进入配置项界面，进行配置。
  • 获取配置项配置的值的实现（如何使用）：var config = ConfigService.GetConfig(new 规则生成说明类(),typeof(使用配置项的实体类))；通用config.属性名可以获取到界面配置的值，要注意判断配置项是否为空。

        throw new ValidationException("产品管理未维护打印模版，或者维护了标签模版但是未启用".L10N());
      }

      //2、根据打印类型获取报表处理对象
      var report = ReportFactory.Current.GetReportByExtension(template.Type);//可以选择的模版类型

      //3、获取打印实体对象
      // var printableType = Type.GetType(template.EntityType);

      //3、获取打印数据
      var printData = RT.Service.Resolve<ProductManagementController>().GetProductManagementDataById(ids);

      //4、创建实体打印对象，如果清楚实体打印对象，自己你一个出来也可以
      var printable = new ProductManagementLabelPrintable();

      //5、调用打印处理函数返回打印模版BASE64字符串到前端，用于传输到打印预览页面
      return report.PrintProcess(printable,template.Id,template.Content,()=>{
        return printData;
      });
    }
  }
}
