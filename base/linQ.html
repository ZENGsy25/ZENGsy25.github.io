# 是什么

  • LINQ（Language Integrated Query，语言集成查询）是 C# 3.0 / .NET 3.5 引入的查询能力。
  • 核心是对 IEnumerable<T> / IQueryable<T> 的一组扩展方法，用来筛选、投影、排序、分组、聚合集合数据。
  • 日常开发里最常用的是 LINQ to Objects（查内存集合）。查数据库时走 LINQ to Entities（EF），写法很像，但执行时机和生成 SQL 不同。
  • 使用前引入命名空间：
using System.Linq;
  • 查询依赖 Lambda。() 里是入参，=> 右边是表达式或方法体，类似 JS 箭头函数：
Func<int, bool> isPass = score => score >= 60;

# 两种写法

LINQ 有两种等价写法：方法语法（常用）和 查询语法（像 SQL）。方法语法是基础，查询语法是语法糖。

下面示例共用这份数据：

var students = new List<Student>
{
    new Student { Id = 1, Name = "张三", Age = 20, Score = 88, ClassName = "一班" },
    new Student { Id = 2, Name = "李四", Age = 22, Score = 59, ClassName = "二班" },
    new Student { Id = 3, Name = "王五", Age = 20, Score = 95, ClassName = "一班" },
    new Student { Id = 4, Name = "赵六", Age = 21, Score = 72, ClassName = "二班" }
};

class Student
{
    public int Id { get; set; }
    public string Name { get; set; }
    public int Age { get; set; }
    public int Score { get; set; }
    public string ClassName { get; set; }
}

# 方法语法

var result = students
    .Where(s => s.Score >= 60)
    .OrderByDescending(s => s.Score)
    .Select(s => s.Name);

# 查询语法

from、in、select 三个关键字缺一不可。

var result = from s in students
             where s.Score >= 60
             orderby s.Score descending
             select s.Name;

# 延迟执行

  • Where、Select、OrderBy、GroupBy 等大多数查询不会立刻跑，只是把查询条件记下来。
  • 真正遍历时（foreach、ToList()、Count()、First() 等）才会执行。
  • 好处是可以继续拼接条件；坏处是多次遍历会重复计算。
var query = students.Where(s => s.Score >= 60); // 还没查
var list = query.ToList();                      // 这时才真正执行
  • 需要立刻拿到结果时，用转换方法结束查询：ToList()、ToArray()、ToDictionary()。

# 筛选

# Where：按条件过滤

var passed = students.Where(s => s.Score >= 60);

var query = from s in students
            where s.Score >= 60 && s.Age >= 20
            select s;

# OfType：按类型过滤

适合集合里混了多种类型（例如 ArrayList、object[]）。

object[] mix = { 1, "a", 2, "b", 3.5 };
IEnumerable<int> nums = mix.OfType<int>(); // 1, 2

# 投影

# Select：转换成另一种形状

var names = students.Select(s => s.Name);

var dto = students.Select(s => new
{
    s.Name,
    IsPass = s.Score >= 60
});

var names = from s in students
            select s.Name;
  • Select 常和匿名类型一起用：new { 属性名 = 值 }。
  • 带索引的重载：
var withIndex = students.Select((s, index) => new
{
    Index = index,
    s.Name
});

# SelectMany：把嵌套集合拍平

一个学生有多门课时，用 Select 会得到“集合的集合”，SelectMany 会摊成一条条记录。

var courses = new[]
{
    new { Name = "张三", Items = new[] { "语文", "数学" } },
    new { Name = "李四", Items = new[] { "英语" } }
};

var all = courses.SelectMany(c => c.Items);
// 语文, 数学, 英语

var pairs = courses.SelectMany(
    c => c.Items,
    (c, item) => c.Name + "-" + item
);
// 张三-语文, 张三-数学, 李四-英语

# 排序

var byScore = students.OrderBy(s => s.Score);                    // 升序
var byScoreDesc = students.OrderByDescending(s => s.Score);      // 降序
var then = students.OrderBy(s => s.ClassName).ThenBy(s => s.Score); // 多字段
var reverse = students.Reverse();                                // 反转当前顺序

查询语法：

var query = from s in students
            orderby s.ClassName, s.Score descending
            select s;
  • 第二排序键用 ThenBy / ThenByDescending，不要连续写两个 OrderBy（后面的会覆盖前面的）。

# 分页 / 截取

var first3 = students.Take(3);     // 前 3 条
var skip2 = students.Skip(2);      // 跳过前 2 条
var page = students.Skip(2).Take(2); // 第 2 页，每页 2 条（页码从 0 算）

var takeWhile = students.TakeWhile(s => s.Score >= 60); // 从头取，直到条件不成立
var skipWhile = students.SkipWhile(s => s.Score >= 60); // 从头跳，直到条件不成立

常用分页公式：

int pageIndex = 1; // 第 1 页
int pageSize = 10;
var pageData = students.Skip((pageIndex - 1) * pageSize).Take(pageSize).ToList();

# 判断

这些方法会立即执行。

bool hasPass = students.Any(s => s.Score >= 60);     // 是否存在
bool allPass = students.All(s => s.Score >= 60);     // 是否全部满足
bool empty = !students.Any();                        // 是否为空，比 Count() == 0 更合适
bool hasName = students.Select(s => s.Name).Contains("张三");

# 取单个元素

这些方法也会立即执行。找不到或找到多条时，行为不一样，要分清。

方法 找不到 找到多条
First 抛异常 返回第一条
FirstOrDefault 返回默认值（引用类型是 null） 返回第一条
Last / LastOrDefault 同上，取最后一条 取最后一条
Single 抛异常 抛异常
SingleOrDefault 返回默认值 抛异常
ElementAt 抛异常 按下标取
ElementAtOrDefault 返回默认值 按下标取
var firstPass = students.First(s => s.Score >= 60);
var maybe = students.FirstOrDefault(s => s.Score >= 99); // 可能为 null
var onlyOne = students.Single(s => s.Id == 1);           // 必须恰好 1 条
var third = students.ElementAt(2);
  • 不确定有没有数据时用 FirstOrDefault，取到后先判空。
  • 按业务主键查、必须唯一时用 Single / SingleOrDefault。

# 聚合

这些方法也会立即执行。

int count = students.Count();
int passCount = students.Count(s => s.Score >= 60);
int sum = students.Sum(s => s.Score);
double avg = students.Average(s => s.Score);
int max = students.Max(s => s.Score);
int min = students.Min(s => s.Score);
int maxAge = students.Max(s => s.Age);

Aggregate 是自定义累计，类似 reduce：

string names = students.Select(s => s.Name)
    .Aggregate((a, b) => a + "," + b);
// 张三,李四,王五,赵六

空集合上调用 Average / Max / Min 会抛异常，需要先判断，或用可空版本：

double? avg = students.Select(s => (int?)s.Score).Average();

# 去重和集合运算

int[] a = { 1, 2, 2, 3 };
int[] b = { 3, 4 };

var distinct = a.Distinct();     // 1, 2, 3
var union = a.Union(b);          // 1, 2, 3, 4   并集（去重）
var concat = a.Concat(b);        // 1, 2, 2, 3, 3, 4  直接拼接
var intersect = a.Intersect(b);  // 3            交集
var except = a.Except(b);        // 1, 2         差集（在 a 不在 b）

引用类型默认按引用比较。要按某个字段去重，需要自定义比较器，或先投影：

var uniqueNames = students.Select(s => s.Name).Distinct();

# 分组

var groups = students.GroupBy(s => s.ClassName);

foreach (var g in groups)
{
    Console.WriteLine(g.Key);          // 班级名
    Console.WriteLine(g.Count());      // 该班人数
    Console.WriteLine(g.Average(x => x.Score));
    foreach (var s in g)
    {
        Console.WriteLine(s.Name);
    }
}

var query = from s in students
            group s by s.ClassName into g
            select new
            {
                ClassName = g.Key,
                Count = g.Count(),
                AvgScore = g.Average(x => x.Score)
            };

多字段分组：

var groups = students.GroupBy(s => new { s.ClassName, s.Age });

# 连接

类似 SQL 的 JOIN。

var classes = new[]
{
    new { ClassName = "一班", Teacher = "周老师" },
    new { ClassName = "二班", Teacher = "吴老师" }
};

# Join：内连接

两边都能匹配上的才留下。

var inner = students.Join(
    classes,
    s => s.ClassName,
    c => c.ClassName,
    (s, c) => new { s.Name, c.Teacher }
);

var query = from s in students
            join c in classes on s.ClassName equals c.ClassName
            select new { s.Name, c.Teacher };

注意：查询语法里必须写 equals，不能写 ==。

# GroupJoin：分组连接（常用来模拟左连接）

var left = classes.GroupJoin(
    students,
    c => c.ClassName,
    s => s.ClassName,
    (c, ss) => new
    {
        c.ClassName,
        c.Teacher,
        Students = ss.ToList()
    }
);

查询语法的左连接写法：

var query = from s in students
            join c in classes on s.ClassName equals c.ClassName into gj
            from c in gj.DefaultIfEmpty()
            select new
            {
                s.Name,
                Teacher = c == null ? "无" : c.Teacher
            };

# 转换结果

方法 作用
ToList() 变成 List<T>，立刻执行
ToArray() 变成数组，立刻执行
ToDictionary(key, value) 变成字典，key 必须唯一
ToLookup(key) 类似分组字典，key 可以重复
AsEnumerable() 后面改走内存 LINQ（EF 里常用）
AsQueryable() 变成可查询对象
Cast<T>() 把非泛型集合转成 IEnumerable<T>，失败会抛异常
DefaultIfEmpty() 空序列时给一个默认元素，左连接会用到
var dict = students.ToDictionary(s => s.Id, s => s.Name);
var lookup = students.ToLookup(s => s.ClassName);
var names = lookup["一班"].Select(s => s.Name);

# 查询语法常用关键字

var query = from s in students              // 数据源，必须有
            let pass = s.Score >= 60        // 临时变量
            where pass                      // 过滤
            orderby s.Score descending      // 排序
            group s by s.ClassName into g   // 分组
            select new                      // 投影，必须有
            {
                ClassName = g.Key,
                Count = g.Count()
            };
  • let：先算出中间值，避免重复写长表达式。
  • into：把当前结果接到下一步（分组、join 之后常用）。

# 几个组合示例

# 及格名单，按分数倒序，只要姓名

var names = students
    .Where(s => s.Score >= 60)
    .OrderByDescending(s => s.Score)
    .Select(s => s.Name)
    .ToList();

# 各班平均分，平均分从高到低

var stats = students
    .GroupBy(s => s.ClassName)
    .Select(g => new
    {
        ClassName = g.Key,
        Avg = g.Average(x => x.Score),
        Count = g.Count()
    })
    .OrderByDescending(x => x.Avg)
    .ToList();

# 按班级取每班第一名

var top = students
    .GroupBy(s => s.ClassName)
    .Select(g => g.OrderByDescending(x => x.Score).First())
    .ToList();

# 使用注意

  • 记得 using System.Linq;，否则看不到这些扩展方法。
  • 链式调用从左到右执行：先 Where 再 Select，能少投影就少投影。
  • 延迟查询不要重复 foreach。要复用结果就 ToList() 存下来。
  • Count() 会遍历整个序列。只判断空不空时用 Any()。
  • First() 找不到会抛异常，接口入参不确定时用 FirstOrDefault()。
  • ToDictionary 遇到重复 key 会抛异常，这时用 ToLookup 或先 GroupBy。
  • LINQ to Objects 在内存里跑；EF 里的 IQueryable 会翻译成 SQL。写不进去 SQL 的逻辑（本地方法、复杂 if）可能导致整表查到内存再过滤。
  • EF 场景下需要先在数据库过滤，再切到内存时用 AsEnumerable() / ToList()，避免把过滤条件留在可翻译区域之外。
