# setup

  • setup() 钩子是在组件中使用组合式 API 的入口
  • setup()钩子的执行时机在 beforeCreate 之前，this 是 undefined
  • 我们可以使用响应式 API 来声明响应式的状态，在 setup() 函数中返回的对象会板和组件实例。
  • 其他的选项也可以通过组件实例来获取 setup() 暴露的属性：
export default {
  props: {
    title: String,
  },
  //代替vue2中的data
  setup(props, context) {
    const count = ref(0);
    // 返回值会暴露给模板和其他的选项式 API 钩子
    return {
      count,
    };
  },
  mounted() {
    console.log(this.count); // 0
  },
};
